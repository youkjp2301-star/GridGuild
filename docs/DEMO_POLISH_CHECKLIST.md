검증: 최종 APK·테스트 APK·Lint 빌드 성공(49초), 단위68개, Android44개 전부 통과(249.624초). Lint 오류0/기존 경고12. 원래 원장은 테스트 전 백업으로 복원하고 SHA256 일치를 확인했다. 화면과 실제 시작 영상은 로컬 `artifacts/demo-polish-v090/`에 보관한다(Git 제외).

직접 시험: HOME 최초 등록 후 **충전 테스트**를 누른다. 이미 오늘 보상받았으면 연결·테스트의 충전 미션 초기화 후 반복한다. 진행 중 ROUTE 미션이 있다면 완료/취소 후 HOME을 시험한다. 충전소 상태 테스트는 카드의⋮, 전체 상태 섞기는 추천 목록의 조절 아이콘 안에 있다.

실제 충전소 API/계통/실차 시간 제어/온라인 랭킹을 구현한 것은 아니다. Mock 조작은 실제 기어·CarUxRestrictions를 우회하지 않으며 실제 SDK 종단 미검증 항목은 기존 개발 기록을 따른다.
