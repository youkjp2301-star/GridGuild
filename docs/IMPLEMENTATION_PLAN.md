## 구현 순서

1. 공식 문서 + 실제 배포 AAR의 공개 시그니처/권한 검증.
2. Gradle Wrapper, Kotlin JVM core, Compose app 생성 및 공식 Maven 의존성 연결.
3. 순수 미션·레벨·시즌 로직 → DataStore 원자 저장 → 명시적 Mock/실제 저장소.
4. 안전 상태·수명주기 연결 → 4탭 UI/도시 Canvas → 테스트 콘솔.
5. assembleDebug + JVM 테스트 + lintDebug, 오류 수정.
6. Pleos 에뮬레이터 설치/실행 후 SDK 연동 확인, 불가 항목은 미검증으로 기록.
7. APK, 실행 스크립트, 검증 보고서 제공.

## 결정한 MVP 규칙

- XP 기준: 녹색 미션 120 / 야간 미션 100. 샘플 3곳을 같은 한국 날짜에 모두 완료하면 50 추가.
- 같은 충전소 미션은 한국 날짜당 1회. SOC 감소·출처 변경·오래된 값·미확인 충전 상태는 지급하지 않음.
- 야간 22–07시 미션은 그 시간 안에서 시작·완료. 상시 fixture는 00–24시.
- 지역 총 XP와 개인 총 XP는 원장 이벤트에서 계산. 시즌은 Asia/Seoul 월 기준으로 별도 계산.
- 모드 변경 시 진행 중 미션 취소. 기록을 실제 인증 성과로 승격하지 않음.
- 실제 서비스 연결 결과, 기능 capability, 수신한 데이터의 신선도를 별도로 검사.
- 게임 앱이므로 distractionOptimized=true를 선언하지 않는다. OS의 주행 차단 화면을 우회하지 않는다.

최종 실제 검증 결과는 [TEST_REPORT.md](TEST_REPORT.md)를 기준으로 한다.
