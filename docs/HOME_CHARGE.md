# HOME CHARGE — 우리 집 충전 0.9.0

2026-11-09 수정: 주 화면에16:00–17:00,22:00–23:00 두 모의 시간대를 표시한다. Mock의 시간 조건은 자동 충족으로 처리한다. 등록 후 **충전 테스트 · +120 XP**는 미션 참여/충전ON/SOC 목표 도달 샘플을 같은 관측 경로에 넣으며 직접 원장을 조작하지 않는다. 수동 ON/SOC 테스트도 현재 실제 시간이 예시 밖이라는 이유로 보상을 막지 않는다.

Mock 우회는 state.mode·mission.source·vehicle.source가 모두 MOCK일 때만 적용한다. 실제 차량은 관측 신선도/출처·현재 승인 시간대·저SOC/목표/출발 안전 정책을 유지한다. 실제 시간대는 한국 시각 기준 시작 포함/종료 제외이며16–17시 또는22–23시 중 유효한 다음 구간을 고른다. 주행 UX 제한·하나의 미션 슬롯·같은 완료 날짜1회·목표 SOC 초과 방지는 그대로다. 반나절을 기다리거나 시스템 시계를 바꾸지 않고 시험할 수 있다.

이하0.6.0의 기존 흐름/설계 기록을 보존한다. 아래 옛23~03시/Mock 대기 설명은 위0.9.0 정책으로 대체한다.

사용자 변경 요청일: 2026-11-05 (Asia/Seoul).

## 최소 사용 흐름

1. 우리 집 충전소 이름을 처음 한 번 등록한다. 이름은 로컬에 저장하며 실제 충전 장소 인증과 구분한다.
2. 현재 SOC·오늘 추천 안내·120 데모 XP를 보고 ‘충전 미션 참여하기’를 누른다.
3. 평소처럼 충전한다. 앱은 충전 ON과 신선한 동일 출처 SOC의 2%p 상승을 확인한다.
4. 조건이 맞으면 개인·도시에 각각120 XP를 같은 원장에 저장하며 랭킹/도시 레벨에 자동 반영한다.

차량 충전 시작·중지·충전 목표를 제어하지 않는다. SDK 충전 스위치 ON만으로 전력 유입이나 장소·계통 기여를 인증하지 않는다.
HOME 보상은 모두 데모이며, 같은 한국 완료 날짜에 1회다. ROUTE와 하나의 진행 미션 슬롯을 공유하므로 동시에 두 미션에 참여하지 않는다.

## 선택 고급 설정과 보수적 기본값

목표 SOC(1~100)와 출발 HH:mm은 톱니바퀴에 두고 저장값을 재사용한다. 비워도 참여할 수 있다.

| 상태 | 기본 안내/판정 |
|---|---|
| 출발 시각 없음 | 필요할 때 바로 충전. 지연을 권하지 않음 |
| SOC 미확인 | 차량 데이터 확인, 참여 제한 |
| SOC 30% 미만 | 즉시 충전 우선. 30%는 MVP 정책값이며 주행 가능 거리 계산이 아님 |
| 설정 목표 SOC 미달 | 충전 우선. 목표 도달 시간은 계산하지 않음 |
| 출발이 모의 야간 구간 종료+3시간보다 이른 경우 | 지연 없이 충전 우선 |
| SOC 90% 이상 | 추가 충전 보상을 권하지 않고 참여 제한 |
| 현재 SOC+2%p가 저장 목표를 초과 | 보상 때문에 목표를 넘기지 않도록 참여 제한 |
| 위 제약이 없고 출발 여유가 있음 | 밤23:00~다음 날03:00 모의 구간 표시 |

출발 시각은 다음으로 다가오는 해당 한국 시각이다. 모의 야간 구간은 현재가 03시 전이면 전날23시~오늘03시, 아니면 오늘23시~다음 날03시다.
종료+3시간 경계는 허용하며, 이는 충전기 출력/용량에 근거한 완료 시간 보장이 아니다. 실제 충전 계획 최적화나 전력망 데이터가 없다.
미래 야간 미션에 참여한 뒤 배터리/설정이 보수적 즉시 충전 조건으로 바뀌면, 다음 신선한 샘플부터 즉시 참여 구간으로 바꾼다. 그 샘플을 새 기준으로 삼아 즉시 보상하지 않는다.

## 자동 판정과 저장

- 일반 즉시 참여는 참여 당시의 SOC를 기준으로 한다. 미래 야간 참여는 기준 SOC를 비워 두고, 해당 구간 안에서 받은 첫 신선한 샘플로 기준을 잡는다.
- 첫 기준 샘플 자체로 보상하지 않는다. 구간 전 상승분, 구간 전 시각의 지연 샘플, 오래된/미래/역순/다른 출처 샘플은 지급에 사용하지 않는다.
- 완료 샘플에서 충전 스위치가 ON이어야 한다. OFF/UNKNOWN, ON만 유지되거나 SOC만 오른 경우는 보상하지 않는다.
- 구간 종료 시각은 포함하지 않는다. 시간이 지난 미션은 지급 없이 종료한다. 중복 콜백 및 재참여로 같은 완료 날짜에 HOME 보상을 반복하지 않는다.
- schema3에 등록·선택 설정·미션 종류·구간·기준 SOC·마지막 관찰 시각을 저장한다. schema1/2의 기존 XP/진행 ROUTE/초기화 플래그는 읽어서 보존한다.
- 기존 초기화 규칙을 공유한다. 충전 미션 초기화는 HOME 진행/당일 판정도 초기화하며 이미 지급한 XP는 보존한다. 전체 초기화는 집 등록/고급 설정까지 지운다.
- 프로세스가 종료되면 상시 관찰하지 않는다. 재실행 후 신선한 자료부터 이어가며 관찰하지 못한 과거 충전을 소급 추정하지 않는다.

## ROUTE 유지와 함께 반영한 요청

- 삼락·센텀·광안에 고정 가상 충전소를 한 곳씩 추가했다. 전체6곳, 기본 삼락 목적지2곳·센텀/광안 권역4곳·기장0곳이다.
- 기존 3곳의 ID·100/120 XP·참여 시간과 기본3곳 추가50 XP 정책은 유지했다. 새 후보/HOME은 이 추가 보상 필수 목록에 넣지 않았다.
- 위치 관계도는 후보 목록 아래로 옮겼다. 실제 지도/시설/도로가 아니며 후보는 직선거리 반경5km다.
- ‘권장 시간 외’를 ‘미션 참여 시간 아님’으로 변경했다. 센텀의 22~07시는 보상 미션 시간이며 시설이 닫혔다는 뜻이 아니다. 실제 운영정보는 미연동이다.

## 검증 범위와 후속 경험

코드/컴파일 및 표준 Android Mock에서 HOME 참여→충전 ON/SOC 상승→개인/도시 각120 XP·Lv.2·재진입을 검증한다. 실제 Pleos에서 HOME 충전 변화 종단 지급이 성공했다고 표시하지 않는다.
Vehicle 이전 현재값/P/UX 실응답 성공과 Navi 목적지 콜백 미수신 상태는 유지된다.

향후에는 사용자 사전 동의와 중복/출처/장소 검증, 지속 관찰 조건이 갖춰지면 별도 참여 버튼 없이 평소 충전에서 조건을 판단하는 경험을 검토한다. 현재 릴리스는 한 번의 참여를 유지하며 자동 참여를 구현한 척하지 않는다.
