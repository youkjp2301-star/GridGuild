# GridGuild Bento UI — 0.14.0

2026-11-12 사용자 전면 리디자인 지시를 기존 PRD에 추가 적용한다. 첨부9.70초 영상의 실제19프레임을 확인했다. 밝은 바탕, 서로 다른 카드 비율, 소수의 차콜 카드, 녹색 포인트, 원형 게이지·숫자·선택 상태의 움직임을 차량 충전과 도시 성장에 맞게 재구성한다. 레퍼런스 화면이나 자산을 앱에 복사하지 않는다.

## 토큰과 레이아웃

| 역할 | 값 |
|---|---|
| 배경 / 카드 | #F6F7F5 / #FFFFFF |
| 보조 면 / 선 | #ECEFEC / #E6EAE6 |
| 본문 / 보조 본문 | #171A18 / #66716B |
| 녹색 포인트 / 녹색 글씨 | #37C67A / #187344 |
| 강조 면 / 강조 면 보조 글씨 | #202522 / #B8C6BD |
| 모서리 / 내부 여백 / 간격 | 24dp / 18dp / 10–12dp |
| 화면 여백 / 조작 높이 | 16dp / 최소48dp, 주요 버튼52dp |

지정 색상의 sRGB 상대휘도로 계산한 대비: 진한 글씨/녹색 버튼7.95:1, 보조 글씨/앱 배경4.72:1, 진녹색/연녹색 면5.16:1, 밝은 보조 글씨/차콜8.78:1. 장문에 밝은 녹색을 사용하지 않는다. 과한 그림자·네온·반복 바운스·파티클은 사용하지 않는다.

좁은 화면은 한 열을 기본으로 숫자 카드만 짝지으며, 충분한 콘텐츠 폭에서 SOC/미션과 충전소/지역 순위를 다른 비율의 두 열로 배치한다. 홈 충전은720dp 이상에서 미션·차량/설정/시간의 두 열을 사용한다.840dp 이상은 좌측 탐색, 좁은 화면은 하단 탐색이다. 화면 전체를 세로 스크롤하고 고정 카드 높이로 콘텐츠를 잘라내지 않는다.

## 화면과 공통 컴포넌트

- BentoComponents: BentoCard, StatCard, SocGauge, AnimatedNumber, BentoProgress, StatusBadge, PrimaryButton, SectionHeader.
- 홈: 실제 SOC/저장 목표, 오늘 미션 강조, 개인 XP/도시 단계, 큰 도시 비주얼·진행, 기존 추천 정책의 충전소, 지역 샘플 순위.
- HOME: 등록·선택 설정·두 모의 시간·참여·자동 진행·완료·도시 CTA. 출발/목표 미설정은 그대로 표시한다.
- ROUTE: 목적지, 큰 위치도, 선택 상태와 네 가용 현황, 호환·요청 상태·미션/완료 카드·즐길거리. 위치도는 실제 지도·도로 경로가 아닌 기존 가상 좌표 관계도다.
- 내 도시: 큰 이미지 한 장, 저장 도시 XP와 단계/성장, 해금한 컬렉션. 기존 이미지와 미해금 제한을 유지한다.
- 랭킹: 내 순위 강조, 실제 저장 성과를 합산한 샘플 목록, 바로 위와 XP 차이. 이전 순위는 같은 모드/지역/기간/필터에서 앱이 실제 관측한 값만 사용하고 조건 변경 시 초기화한다.

## 움직임과 상태 경계

| 동작 | 시간 / 조건 |
|---|---|
| 카드 등장 | 220ms 페이드+10dp 이동, 최대5개×35ms 시차 |
| 버튼 / 카드 누름 | 130ms, 반복 바운스 없음 |
| 카드 확장 | 240ms |
| SOC / 숫자 / 진행률 | 실제 값 변경에만450ms |
| 탐색 이동 | 기존 방향 기반240–300ms |
| XP 완료 피드백 | 저장된 새 보상만600ms 도시 수치·막대 반영 |

차량 heartbeat나 일반 재구성으로 등장/보상 효과를 반복하지 않는다. OS 애니메이터 배율0에서는 이동·수치 효과를 즉시 적용한다. 기존 최소3초 초기 로딩은 유지하며 주행 제한은 기다리지 않고 즉시 우선한다. 보상 오버레이는 아래 버튼 입력을 막지 않는다.

## 보존되는 로직

core·ViewModel·Repository·DataStore·SDK 버전/인증·원장·보상 조건은 변경하지 않는다. 신선하고 현재 모드에 맞는 SOC만 수치와 권고에 사용한다. 개인 XP와 도시 XP, 샘플 공동 점수는 구분한다. 목표·출발·ETA·순위 변동을 만들지 않는다.

HOME/ROUTE 이동 요청은 저장된 탭 상태와 별개의 단발 요청 ID로 처리한다. 보통의 탭 복귀는 이전 선택을 유지하고 홈 CTA는 요청한 HOME/ROUTE/지역 랭킹을 연다. 실제 P+CarUxRestrictions, D/UX 제한, Mock/SDK 분리와 데이터 출처 안내를 유지한다.

실제 빌드·화면·원장/안전 회귀 결과와 미완료 범위는 TEST_REPORT 및 DEV_LOG에 기록한다. 자동 fixture는 별도 QA에만 실행하고 원본 AVD는 초기화하지 않는다.
