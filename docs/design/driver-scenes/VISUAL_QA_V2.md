## 판정 기준

1. **도로 위 시점:** 차도 또는 시대에 맞는 수레길이 화면 하단부터 이어지고 카메라가 그 진행 공간 안에 있는가.
   항공·등각·전망대·해변 산책로·별도 랜드마크 엽서 구도는 불합격이다.
2. **눈높이와 원근:** 지나치게 높은 카메라나 광각 왜곡 없이, 가로·교량·지붕·건물이 같은 공간의 투시로 읽히는가.
3. **레벨 대응:** Lv.2의 흙길·초가집, Lv.12의 발전된 미래 도로처럼 도로 재료·건축·인프라가 단계와 맞는가.
   전경뿐 아니라 원경의 시대가 맞아야 한다.
4. **지역과 랜드마크 통합:** 광안리는 해안·교량 계보, 센텀은 문화공간·넓은 지붕의 계보가 거리와 연결되는가.
   현대 랜드마크를 초기 시대에 그대로 얹거나, 두 지역에서 같은 거리에 랜드마크만 바꾼 인상을 주면 수정한다.
5. **재료와 구조 표현:** 흙·석재·목재·벽돌·금속·유리에 질감 차이가 있고, 지지부·접합·그림자·거리 규모가 시각적으로 연결되는가.
   반복되는 동일 타워, 녹아내린 부재, 과도한 광택·네온·후광 등 눈에 띄는 생성 흔적을 확인한다.

**PASS**는 위 조건에서 중대한 시각 문제를 발견하지 못했다는 뜻이다. **P1/REVISE**는 핵심 요구와 어긋나 수정 전 승인하지 않는 경우다.
**P2 주의**는 비차단 시각 한계로, 관찰 내용과 설명 범위를 함께 남긴다.

카메라 눈높이 1.3m·렌즈 28mm·소실점 높이 43%는 생성 지시의 목표값이다. 생성된 2D 이미지에서 그 값을 실측하거나
일치시켰다고 확인하지 않았다. 검수한 장면의 소실점은 대체로 화면 중간 부근에 보이며, 정확한 고정 수치를 충족했다고 표시하지 않는다.

## 반려와 수정 이력

### 센텀 Lv.4 — 시대와 맞지 않는 원경

- **원본: REVISE / P1.** 전경의 벽돌 공연장·철제 지붕은 산업 단계와 맞았으나, 중앙 원경에 현대 백색 사장교와 고층 주거군이 남아 있었다.
- **수정본: PASS.** 해당 현대 원경을 낮은 산업 건물·교량·배로 교체했다. 전경 재료와 도로 위 원근은 유지했다.
- 반려된 생성 원본은 기본 생성 이미지 폴더에 보존되며, 현재 `driver_centum_lv04_v2.png`는 수정본이다.

### 센텀 Lv.12 — 두 지역의 거리 구성이 거의 동일

- **원본: REVISE.** 운전자 차도 시점 자체는 맞았으나, 광안리 Lv.12와 왼쪽 곡면 고층군·고가 차양·조경이 거의 같아 우측 랜드마크만 바꾼 인상이 남았다.
- **수정본: PASS.** 왼쪽을 서로 다른 비례의 직교 세라믹 문화·업무 건물, 상점, 지상 트램과 보행자로 바꿨다. 우측 빅루프·곡면 지지부와 도로 원근은 유지했다.
- 반려된 생성 원본은 기본 생성 이미지 폴더에 보존되며, 현재 `driver_centum_lv12_v2.png`는 수정본이다.

- **광안리 Lv.5: 수정 후 PASS.** 초기 PASS/P2의 우측 원경 주거군을 낮은 붉은 지붕 집으로 교체한 것을 확인했다. 기존 도로 시점·석조 교량·전면 근대 건물은 유지됐다.

## 남아 있는 시각 한계

- 광안리 Lv.1 목교의 좁은 폭은 실제 차량 통행 규격·안전성이 확인된 것이 아니다. 도로 위 정차 장면으로 읽히지만 실제 주행 가능 경로라고 설명하지 않는다.
- 광안리 Lv.5 원경 주거군의 시대감 지적은 수정 후 해소됐지만, 실제 역사 복원이나 특정 연도의 광안리로 표시하지 않는다.
- 광안리 Lv.12의 차량·보행자·도로 사용감 보완을 확인했으나 미래 건축에는 건축 CG 같은 인상이 일부 남는다. 생성 흔적이 완전히 제거됐다고 보장하지 않는다.
- 센텀 Lv.7의 좌측 공연장 문제는 우측 재배치로 해소됐다. 다만 모든 단계가 정확히 같은 좌표·방향에서 촬영/렌더링된 장면인 것은 아니며 운전자 눈높이·도로 위 시점의 정성적 일관성을 확인한 것이다.
- 초기 단계의 교량·공연장은 현대 광안대교·영화의전당을 상상해 발전시킨 **가상 전신**이다. 실제 과거에 해당 건축물이 있었다는 뜻이 아니다.
- 모든 신규 장면은 내장 이미지 생성 도구로 만든 가상 도시 이미지다. 실제 촬영 사진·실시간 카메라·현재 도로·실측 지도·완전한 3D 공간이 아니다.
- 지지부·케이블·부재의 시각 연결을 확인했을 뿐 구조 계산·법규·교통 운행 안전성 검증은 수행하지 않았다.
