# GridGuild 승인 디자인 방향 · 0.7.0

2026-11-05. 사용자 승인: “ㅇㅇ 대충 그런 느낌으로 일단 계속 진행해”. 이후 재질·건물 다양성·조명 디테일 추가 요청을 적용했다.

[승인 시안02](gridguild-visual-direction-v2.png)는 구성 검토용 생성 이미지이며 실행 화면이 아니다. UI 구성은 유지하며 사용자의 최신 요청에 따라 도시만 **v4 정밀 건축 모형 스타일**로 변경했다. 반려된 시안01은 같은 폴더, v3 아트는 `previous-assets/`에 보존한다. [최종 아트 생성 프롬프트](CITY_ART_V4_PROMPTS.md).

- 크림 배경, 종이색 카드, 포레스트 그린, 차콜, 얇은 구획선. 투명도가 낮은 탐색 패널로 글자 대비를 유지한다. 실시간 배경 블러는 사용하지 않는다.
- 홈 도시는 중간 폭에서 전폭, 넓은 화면에서 보조 수치 대비 2.6배 폭이다. 메뉴는 홈 · 미션 · 내 도시 · 랭킹이다.
- 메뉴 호버·키보드 포커스·선택·누름을 구분한다. 누르면 .96배로 반응하고 목적지 순서에 따른 실제 두 화면의 슬라이드·페이드가 약300ms 진행된다. 화면별 저장 가능한 상태를 유지한다.
- 도시 아트는 최신 첨부2장의 정밀 건축 모형처럼 실제 건축 비례, 낮은 채도, 회청색 물, 자연 녹지와 부드러운 낮 조명을 사용한다. 석재 줄눈·미장 벽·목재 결·벽돌·슬레이트·구리·유리 창호·금속을 구분하고 주택·공방·공공시설·업무 빌딩 외형과 옥상 설비·차선·철도·태양광 세부를 달리한다. 기존의 주황 지붕/과장된 식생 스타일은 적용하지 않는다.
- 로딩은 별도4프레임의 같은 소규모 건물이 기초→골조→벽체→완성되는 장식 애니메이션이다. 레벨 변화나 미해금 도시 미리보기가 아니다. 실제 DataStore/도시 이미지 준비 중에 표시하며 강제 대기 시간·가짜 진행률은 넣지 않는다. Mock 연결·테스트에서 연출만 따로 볼 수 있다.
- XP는 이미 저장된 새 원장 ID를 감지한 뒤 작은 청록 조각이 성장 막대로 모이고 수치가 증가한다. 노란 원·발광 후광·새 XP 지급 로직은 없다. 처음 읽은 과거 원장·초기화·동일 ID 갱신은 재생하지 않는다. 연속 동일 금액도 독립 이벤트로 처리한다.
- P단·실제 플랫폼 UX 제한과 미래 도시 잠금은 모션 바깥에서 유지한다. OS 애니메이션 배율0에서는 정지 로딩·즉시 전환을 사용한다. XP 효과는 짧은 정지 결과로 대체한다.

3D 모델을 실시간 렌더링하는 기능이나 생성 동영상 파일을 재생하는 기능은 아니다. 런타임은 PNG 프레임과 실제 Compose 전환·입자 애니메이션이다.
