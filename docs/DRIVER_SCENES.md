# 도로 위 운전자 1인칭 도시 · 0.11.0

기준일: **2026-11-10**. 사용자 정정 요구를 반영한 장면·렌더링·검수 사양이다.
자산24개 제작·원본 시각 검수·APK 빌드를 완료했다. 대표 Lv.2/12의 실제 실행도 확인했다.
전체 구성표만으로 모든 기기 검증이 완료됐다고 판단하지 않는다.
실제 수행한 검사와 최종 결과는 [TEST_REPORT.md](TEST_REPORT.md), 작업 인계는 [DEV_LOG.md](../DEV_LOG.md)를 따른다.

## 사용자가 경험해야 하는 장면

사용자는 가상 도시의 **차도 위에 정차한 운전자 눈높이**로 들어간다.
도로가 화면 하단까지 이어지고, 도로 양옆의 건물과 교량 또는 문화 공간이 같은 장소의 원근·재질·조명으로 구성된다.
현재 소속 지역의 도시 XP가 발전 단계를 정하고, Mock 내비 목적지가 광안리/센텀 중 장소를 정한다.

0.10.0은 랜드마크 실사 사진에 HUD를 얹어 이 의도를 잘못 해석했다.
0.11.0은 도로·주변 도시·랜드마크를 함께 제작한 **지역별12단계, 총24개 독립 장면**으로 수정한다.
기존 홈/내 도시 컬렉션의 PNG와0.10.0 JPEG는 보존한다. [이전 사진·라이선스 기록](NEUTRAL_CITY.md)은 별도 자료다.

## 실행과 레벨 선택

1. Mock에서 소속 지역을 선택하고 P단·플랫폼 UX 허용을 확인한다.
2. **연결 · 테스트 → N단 도시 체험 · TEST**를 누른다.
3. 기존 목적지가 광안리/센텀이면 그 장소의 현재 레벨 장면을 선택한다. 다른 목적지는 두 장소 중 선택하도록 안내한다.
4. 체험 하단 **광안리 / 센텀시티**도 기존 Mock 목적지 변경·확인 경로를 사용한다. ROUTE 추천에도 같은 목적지가 전달된다.
5. **단계 둘러보기**에서는 현재·이전에 해금한 단계만 선택한다. 미해금 단계는 잠겨 있고, **지금의 도시**로 현재 레벨에 돌아온다.

HUD의 소속 지역·실제 저장 Lv/XP와 현재 둘러보는 단계는 구분한다.
이전 단계 선택은 저장 XP·미션·소속 지역을 변경하지 않는다. 목적지를 바꿔도 소속 지역이 자동 변경되지는 않는다.
지원하지 않는 목적지나 미수신/잘못된 좌표에는 무관한 랜드마크를 임의 표시하지 않는다.

`DriverScene.resolve(city, cityXp, requestedLevel)`은 기존 `CityUnlocks.selection`을 재사용한다.
기본값은 현재 도시 레벨이며, 미해금/잘못된 요청은 현재 레벨로 돌아간다.
UI는 소속 지역과 XP 변화를 반영해 장면을 결정하고, 이미지 로더도 캐시 조회·해독·표시 전에 해금 범위를 확인한다.
XP 초기화나 소속 지역 변경으로 허용 범위가 내려가면 높은 단계의 이전 선택·캐시·전환 중 이미지를 즉시 숨겨야 한다.
검수용 고레벨 fixture는 격리된 테스트 데이터에서만 설정하고 실제 사용자 원장은 시험 전 상태로 복원한다.

## 단계별 도로·랜드마크 계보

각 행의 광안리/센텀은 서로 다른 자산이다. 낮은 단계의 **전신**은 게임 속 가상 설계 계보를 뜻한다.
현대 광안대교나 영화의전당의 실제 역사적 전신이 해당 형태였다고 주장하지 않는다.

| Lv | 단계 | 도로와 주변 도시 | 광안리의 교량 계보 | 센텀의 문화 공간 계보 |
|---|---|---|---|---|
| 1 | 중세 마을 | 개척 흙길 · 초가 마을, 낮고 드문 주택 | 광안대교의 작은 목조 전신 | 영화의전당의 마을 문화 마당 전신 |
| 2 | 성벽 도시 | 흙길 · 초가집 · 성문, 흙벽·목재·석조 기초 | 광안대교의 목조·석조 전신 | 영화의전당의 목조 공연장 전신 |
| 3 | 르네상스 도시 | 돌포장 교역길 · 전통 시장, 목조 상점과 공방 | 광안대교의 전통 교역 교량 전신 | 영화의전당의 전통 극장 전신 |
| 4 | 산업혁명 도시 | 자갈길 · 벽돌 산업 지구, 철제 구조와 창고 | 광안대교의 산업시대 철교 전신 | 영화의전당의 벽돌 공연장 전신 |
| 5 | 근대 도시 | 초기 포장도로 · 시민 거리, 석조·벽돌·초기 콘크리트 | 광안대교의 근대 현수교 전신 | 영화의전당의 근대 시민 극장 전신 |

| 7 | 첨단 산업도시 | 태양광 차양 · 연구단지 도로, 저·중층 연구 시설 | 광안대교 · 태양광 교량 | 영화의전당 · 태양광 문화 지붕 |
| 8 | 스마트시티 | 스마트 도로 · 교통 환승 거점, 명확한 승하차·보행 영역 | 광안대교 · 스마트 교통 연결 | 영화의전당 · 스마트 문화 거점 |
| 9 | 친환경 도시 | 생태 수변 도로 · 빗물 정원, 생태 수로·녹지 테라스 | 광안대교 · 생태 수변 연결 | 영화의전당 · 생태 문화 공간 |
| 10 | 초연결 도시 | 연결 도로 · 입체 보행로, 완결된 고가 교통·보행 연결 | 광안대교 · 입체 교통망 | 영화의전당 · 공중 문화 연결 |
| 11 | 하이테크 미래도시 | 첨단 대로 · 수직 정원 타워, 다양한 계단형 고층 구조 | 광안대교 · 첨단 복합 교량 | 영화의전당 · 하늘 정원 지붕 |

광안리는 해안과 교량의 쌍주탑/쌍문 리듬, 센텀은 넓은 비대칭 지붕과 문화 마당의 계보를 유지한다.
중간 단계는 단순한 색상 변경을 넘어 도로 재료·건축 기술·교통 시설이 달라져야 한다.
특히 Lv.2의 흙길·초가집과 Lv.12의 진보된 도로·랜드마크는 양쪽 지역에서 각각 검수한다.

## 자산과 생성 기록

- 런타임 경로: `app/src/main/res/drawable-nodpi/`.
- 광안리: `driver_gwangalli_lv01_v2.png`~`driver_gwangalli_lv12_v2.png`.
- 센텀: `driver_centum_lv01_v2.png`~`driver_centum_lv12_v2.png`.
- 생성 도구: **내장 image_gen**. 새 PNG는 AI 기반 가상 재구성이며0.10.0 실사 JPEG의 편집본이 아니다.
- [생성 프롬프트 세트](design/driver-scenes/PROMPT_SET_V2.json)와 [생성 기록](design/driver-scenes/GENERATION_LOG_V2.jsonl)을 보존한다.
- 장면에는 HUD·문자·브랜드·차량 실내·보닛·디스플레이 테두리를 그리지 않는다. 레벨/XP·지역 선택·안내는 Compose에서 별도로 표시한다.

프롬프트의 약1.3m 카메라 높이,28mm 렌즈,화면 상단 기준43~55% 부근 소실점은 **생성 지시**다.
출력 PNG에는 실제 카메라 보정 정보가 없으므로 정확한 카메라 높이·소실점 비율을 실측 검증했다고 표시하지 않는다.
실제 판정은 도로 위의 위치, 운전자 눈높이, 하단 차도, 장면 간 시점 일관성에 대한 시각 검수로 한다.

## 시각 검수 기준

| 항목 | 확인할 내용 |
|---|---|
| 도로 위 시점 | 차도가 하단까지 이어지고 카메라가 주행 차로 안에 있는가. 보도·광장·해변에서 랜드마크를 바라보는 구도가 아닌가. |
| 눈높이·원근 | 건물·도로·랜드마크의 원근이 일치하고 운전자 눈높이가 유지되는가. 항공·조감·디오라마 구도로 바뀌지 않았는가. |
| 발전 단계 | 도로·주변 건물·재료·교통·랜드마크가 같은 발전 단계인가. 낮은 단계에 현대 대형 지붕·미래 도로가 섞이지 않았는가. |
| 장소 식별 | 광안리의 해안/교량, 센텀의 비대칭 문화 지붕/마당 계보가 해당 거리 속에 자연스럽게 연결되는가. |
| 구조·재질 | 교량 케이블·상판과 지붕 지지가 이어지고, 질감·그림자·창호·사람 비례가 자연스러운가. 반복 복제 건물·과도한 광택·떠 있는 구조물이 없는가. |
| 앱 안의 장면 | HUD 아래에서도 도로와 랜드마크가 충분히 보이는가. 올바른 장소·레벨 자산이 표시되고 제한 시 즉시 숨겨지는가. |

AI 느낌을 줄이는 것이 제작 목표다. 검수 통과가 모든 생성 흔적 제거 또는 실제 사진 수준의 정확성을 보장하지 않는다.
생성·시각 검수·리소스 검사·빌드·실제 에뮬레이터 응답을 구분하고, 미검증 항목은 완료로 표시하지 않는다.

## 렌더링·안전 경계

- 명시적24개 리소스 레지스트리로 지역과 정확한 레벨을 연결한다. 누락된 자산을 이전 실사 사진이나 다른 단계로 대체하지 않는다.
- 캐시는 `DriverScene(city, level)`을 키로 삼는 최대3장 LRU다. 모든24장을 동시에 해독하지 않는다.
- 비트맵 해독은 IO에서 수행하고 샘플링한다. 새 장면은 기존 최소3초 로딩 정책을 사용하며 캐시 적중 시 불필요한 로딩을 띄우지 않는다.
- OS 모션 설정에 따라 허용된 새 장면에만 짧은 진입 효과를 적용한다. XP/지역 하락·주행 제한 후 높은 단계의 잔상을 유지하지 않는다.
- N TEST는 일시적인 Mock 체험 상태다. **기존 P단 + 실제 플랫폼 UX 보호를 유지하며 실제 기어를 조작하지 않는다.** 확인된 D/UX 제한·플랫폼 불허·백그라운드·SDK 모드 전환 시 종료한다.
- 실제 N단 자동 진입은 미구현·미검증이다. 실제 플랫폼의 정차/중립 허용 계약을 확인하기 전에는 게임 UI 허용 범위를 넓히지 않는다.
- HOME/ROUTE 미션·XP 지급·랭킹·도시 성장·Pleos Vehicle/NaviHelper의 기존 정책과 실제 SDK 종단 검증 상태는 유지한다.

이 기능은 정지된 생성 이미지와 Compose HUD/전환으로 구성한 체험이다.
실시간3D·자유 공간 이동·실제 도로/날씨·차량 카메라·실제 역사로 사용하지 않는다.
GitHub 원격은 미설정이며, 다른 PC로의 원격 동기화가 완료되었다고 표시하지 않는다.

## 확인된 단위 검사와 후속 검증

`DriverSceneTest` 신규7개를 포함한 `:core:test` **78개 통과**를 확인했다.
여기에는24개 키와 메타데이터, 모든 XP 경계, 해금 범위, XP 하락 후 재잠금, 목적지별 자산 선택을 포함한다.
이 결과는 이미지 내용·24개 PNG 해독·APK 실행·실제 SDK 성공을 검증한 결과가 아니다.
자산 검수와 앱 빌드·에뮬레이터 결과는 [TEST_REPORT.md](TEST_REPORT.md)에 실제 수행 후 기록한다.

에뮬레이터 System UI/전화 장애는 [별도 원인 진단 기록](EMULATOR_DIAGNOSIS_20261110.md)을 따른다.
QA에서는 앱 실행 전 패키지 무결성 검증 ANR가 확인됐고, 모달 해제 후 홈/기존 도시/새 장면/실제 Back이 정상 동작했다.
원본 AVD의 시스템 종료 원인까지 해결 완료로 표시하지 않는다.
